# Backend — SmartGym Home

## Sobre o módulo
Responsável pelas regras de negócio, processamento das requisições, autenticação e comunicação com o banco de dados.

## Tecnologias
- Node.js
- TypeScript
- NestJS
- PostgreSQL
- API REST

## Funcionalidades previstas
- Autenticação e gerenciamento de usuários.
- Cadastro, consulta, edição e exclusão de equipamentos.
- Gerenciamento das informações da academia.
- Comunicação com o banco de dados PostgreSQL.
- Integração com o microsserviço de Machine Learning.
- Disponibilização de endpoints para o frontend.

## Integrações
O backend receberá requisições do frontend React e consultará o microsserviço Python por meio de uma API REST.
