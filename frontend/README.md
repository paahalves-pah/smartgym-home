# Frontend — SmartGym Home

## Sobre o módulo
Interface web do SmartGym Home, responsável pela interação dos usuários com o sistema de gerenciamento inteligente de academia residencial.

## Tecnologias
- React.js
- TypeScript
- HTML5
- CSS3

## Funcionalidades previstas
- Tela de login e autenticação.
- Dashboard com informações da academia.
- Cadastro e gerenciamento de usuários.
- Cadastro e acompanhamento de equipamentos.
- Visualização de dados e indicadores.
- Exibição de recomendações personalizadas geradas pelo módulo de Machine Learning.

## Integrações
O frontend consumirá a API REST do backend desenvolvido com NestJS para consultar e enviar dados.
